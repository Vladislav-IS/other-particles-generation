# Генерация "остальных" частиц

В репозитории реализовано 2 типа моделей:
- "ванильный" EPiC-GAN (взята из репозитория разработчиков);
- трансформерная версия EPiC-GAN.

## Структура репозитория

```
other-particles-generation/
├── notebooks/                          # IPython-блокноты с экспериментами
│   ├── gauss_B_flows_250.ipynb         # Обучение трансформерной модели (250 эпох, старая версия)
│   ├── models_experiments.ipynb        # Подсчет метрик качества для разных моделей (250 эпох c отбором лучшей модели по валидационной выборке)
│   └── n_modes_experiments.ipynb       # Подсчет метрик качества для трансформерной модели с различным количеством мод в смеси гауссовских шумов (250 эпох c отбором лучшей модели по валидационной выборке)
├── src/                                # Исходники
│   ├── __init__.py
│   ├── сalculations.py                 # Функции физических расчетов и предобработки данных ROOT-файлов 
│   ├── config.py                       # Глобальные переменные с фиксированным значением (коды частиц и т.п.)
│   ├── epic_gan.py                     # Реализация "ванильной" модели EPiC-GAN
│   ├── epic_transformer.py             # Реализация трансформерной версии EPiC-GAN
│   ├── gaussian_mixture.py             # Реализация обучаемой смеси гауссовских шумов
│   ├── inference.py                    # Функции расчета метрик
│   ├── plots.py                        # Функции построения графиков
│   └── training.py                     # Функции обучения моделей разных типов
├── metrics/                            # Значения метрик, полученные в ходе экспериментов
│   ├── models_metrics.csv              # Метрики, полученные в models_experiments.ipynb
│   ├── n_modes_metrics.csv             # Метрики, полученные в n_modes_experiments.ipynb
├── requirements.txt                    # Зависимости для src
└── README.md                           # Описание проекта
```

## Веса обученных моделей

Веса обученных моделей доступны по ссылке: https://drive.google.com/drive/folders/1qHIdn-LAc9ZQlzgLEvmD0H2URpvcgWFJ?usp=sharing. Поясенения по названиям весов:

```
learned_weights/
├── epic_gan<...>.pt                    # "Ванильный" EPiC-GAN 
├── epic_t<...>.pt                      # Трансформерная версия EPiC-GAN (2 обучаемые моды входного шума)
├── fix_3<...>.pt                       # Трансформерная версия EPiC-GAN (3 моды фиксированного шума с фиксированными параметрами)
└── fix_4<...>.pt                       # Трансформерная версия EPiC-GAN (4 моды фиксированного шума с фиксированными параметрами)
```
