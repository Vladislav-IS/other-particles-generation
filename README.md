# Генерация "остальных" частиц

В репозитории реализовано 2 типа моделей:
- "ванильный" EPiC-GAN (взята из репозитория разработчиков);
- трансформерная версия EPiC-GAN.

## Структура проекта

```
other-particles-generation/
├── notebooks/                          # IPython-блокноты с экспериментами
│   ├── gauss_B_flows_250.ipynb         # Обучение трансформерной модели (250 эпох, старая версия)
│   ├── different_models.ipynb          # Подсчет метрик качества для разных моделей (70 эпох)
│   └── different_n_modes.ipynb         # Подсчет метрик качества для трансформерной модели с различным количеством мод смеси гауссовских шумов (70 эпох)
├── src/                                # Исходники
│   ├── __init__.py
│   ├── сalculations.py                 # Функции физических расчетов и предобработки данных ROOT-файлов 
│   ├── config.py                       # Глобальные переменные с фиксированным значением (коды частиц и т.п.)
│   ├── epic_gan.py                     # Реализация "ванильной" модели EPiC-GAN
│   ├── gaussian_mixture.py             # Реализация обучаемой смеси гауссовских шумов
│   ├── inference.py                    # Функции расчета метрик
│   ├── plots.py                        # Функции построения графиков
│   ├── training.py                     # Функции обучения моделей разных типов
│   └── transformer.py                  # Реализация трансформерной версии EPiC-GAN
├── requirements.txt                    # Зависимости для src
└── README.md                           # Описание проекта
```
